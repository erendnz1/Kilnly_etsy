
# CraftPilot AI

AI-powered Etsy Growth Platform.

CraftPilot AI helps Etsy sellers create, optimize, analyze,
and grow their Etsy businesses using artificial intelligence.

## Core Features

- AI Listing Generator
- SEO Optimization
- Keyword Research
- Product Ideas
- Store Health
- Competitor Analysis
- AI Growth Coach
- Trend Radar
- Image Analysis
- Pricing Intelligence
